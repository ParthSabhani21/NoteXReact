📝 NoteX – A Simple Yet Powerful Note-Taking App!
Say hello to my first-ever project built with React and React Native! ⚛️✨
NoteX is a clean, responsive, and user-friendly frontend note application where users can create, view, and manage their notes effortlessly. 📒💡
Currently, it’s a frontend-only project — but I plan to integrate the backend soon using Java and PostgreSQL to make it fully functional and dynamic! 🚀
This project marks the beginning of my journey into the world of modern web and mobile app development — learning, experimenting, and building something that actually works! 🔥
